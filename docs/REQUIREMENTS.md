# System Requirements — OmniVoice TTS Studio

> Ye requirements end user ke liye hain (aap jisko tool denge wo ye check kare).

## Zaroori (Minimum)

| Cheez | Requirement |
|---|---|
| **OS** | Windows 10 / 11, 64-bit |
| **CPU** | Koi bhi 64-bit processor (Intel i3 8th gen ya behtar recommended) |
| **RAM** | 8 GB minimum |
| **Storage** | 3 GB free space (app ~200 MB + models ~900 MB + workspace) |
| **Internet** | Sirf pehli dafa setup ke liye (model download ~900 MB). Uske baad 100% offline |
| **GPU** | Zaroorat **nahi** — ye CPU-only build hai |

## Recommended (Behtar experience ke liye)

| Cheez | Requirement |
|---|---|
| **CPU** | Intel i5 8th gen+ / Ryzen 5 ya behtar (jitne zyada cores, utni tez rendering) |
| **RAM** | 16 GB |
| **Storage** | SSD (model load aur export tez hota hai) |

## Notes

- **Python install karne ki zaroorat nahi** — installer mein sab kuch bundled hai.
- **Antivirus** pehli dafa warning de sakta hai (naye .exe par common hai) — "Run anyway" karein.
- Lambi voiceover (10-15 min) par rendering mein waqt lagega — ye normal hai, CPU par audio ban raha hota hai. App band na karein. Andaza: i5 jaisi machine par 14 min ki voiceover ~2 ghante (single) ya 4-5 ghante (lambi chained) mein banti hai — raat ko batch laga kar so jayein.
- Koi account, login ya API key ki zaroorat nahi.
